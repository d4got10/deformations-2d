# Как проверяется результат

Проверка идёт слоями — от модели материала к сверке с диссертацией. Всё автоматизировано:

```bash
cd app
npm test          # модульные тесты (116 шт.)
npm run report    # таблицы сверки → docs/VERIFICATION_RESULTS.md
npm run build && npm run e2e   # интерфейс в браузере
```

Свежие числа — в [VERIFICATION_RESULTS.md](VERIFICATION_RESULTS.md).

# Глава 2 — удар по границе (`tests/impact.test.ts`)

**Метод.** Решение строится как общая задача о распаде разрыва для одномерной нелинейной упругости:
квазипродольная и квазипоперечная волны — ударные (условия (2.40)–(2.42)) или простые (вееры,
интегральные кривые акустического тензора), нейтральная волна поворачивает вектор сдвига.
**Тип каждой волны не задаётся, а выбирается по условию Лакса** — решатель перебирает варианты
«ударная/веер» и берёт допустимый. Авторская постановка (какая волна ударная) не подсказывается.

# Серия ударов — метод волновых фронтов (`tests/fronts.test.ts`)

| Проверка | Результат |
|---|---|

| Три удара: кинематический баланс | ~1e-10 |
| Энергия: работа границы = прирост энергии + Σ диссипации (2.45) на фронтах | расхождение ~1e-16 (мат. 1) … 0.3 % от диссипации (мат. 2) |
| Конечные объёмы сходятся к решению фронтами | средняя разница по p: 6.4e-5 (N = 800) → 2.6e-5 (N = 3200) |

**Растяжение.** Рывок наружу уходит простой волной (оба материала, точный решатель и метод фронтов
согласованы, состояние у границы до 1e-8). Серия «сжатие → растяжение → сжатие» отслеживается без
сбоев; конечные объёмы сходятся к решению фронтами (материал 1: 6.3e-5 → 2.5e-5 при N = 800 → 3200).
Слияние фронтов составной волны (невыпуклость у материала 1) нарушает условия на разрыве с
относительной невязкой ≤ 1e-5.

**Разные скорости сжатия и растяжения** (материал 2, p0 = −0.0005, удар, затем рывок): точный решатель —
ударная волна сжатия 1.070 c1, веер растяжения до 0.914 c1 (среда растянута, p = +1.6e-3); метод фронтов
воспроизводит обе скорости и согласуется с конечными объёмами (N = 3200) до 1.3e-5. Расчёт идёт с
огрублёнными порогами — кинематический баланс ~1e-6 вместо ~1e-10.

# Глава 3 — подвижная нагрузка

## 1. Модель материала (`tests/material.test.ts`)

- σ = ∂W/∂e: напряжения (1.10) совпадают с численной производной потенциала (1.9) на случайных деформациях.
- Общая формула (1.10) совпадает с явными формулами плоской деформации (1.59) и начальным состоянием (3.2).
- Объективность: поворот тензора деформаций поворачивает тензор напряжений.
- При ν = α = β = 0 — закон Гука; при J2 = 0 напряжения не определены (неаналитичность).

## 2. Предельный переход к линейной упругости

При ν = α = β = 0 решатель обязан дать точное решение: sin θ1 = 1/M, sin θ2 = (c2/c1)/M, скачок градиента
на Σ1 поляризован по нормали (P-волна), на Σ2 — по касательной (S-волна), диссипация равна нулю.
Совпадение — до 9–10 знаков.

## 3. Внутренняя согласованность

- Полная система (3.36) из 10 уравнений (как у автора) выполнена с невязкой < 1e-15, хотя решалась
  сокращённая 6-мерная.
- Граничные условия (3.31), непрерывность перемещений на фронтах, G = M sin θ, θ1 > θ2,

## 5. Допустимость ударных волн — две независимые проверки

1. **Диссипация** D = [σ_i1 v_i + ξ σ_i2 v_i] + sξ[W + ½ρv²] ≥ 0 — выведена из закона сохранения энергии;
   алгебраически совпадает с (3.30), если в ней брать напряжения перед фронтом.
2. **Условие Лакса**: скорость характеристик того же семейства перед фронтом < G < за фронтом
   (через акустический тензор, независимо от W).

Тест проверяет, что оба критерия всегда дают один и тот же ответ.

## Открытые вопросы к тексту диссертации

**1. θ2 для материала 1.** Расчёт: 19.49°, текст: 19.2° (G2: 0.5672 против 0.5593). Для материала 2 и для θ1
материала 1 всё сходится до 0.05°. Расчётное θ2 почти равно линейному (19.48°): квазипоперечная волна в
материале 1 почти не чувствует разномодульности. Значение автора *ниже* линейного; при той же нелинейности
это соответствует c2/c1 ≈ 0.559 вместо 0.567, т.е. μ ≈ 33.5 вместо 34.8. Возможна опечатка в одном
из модулей материала 1 или иная деталь расчёта у автора.

**2. Рис. 22а и M_min.** Кривые рис. 22а не согласуются с текстом той же страницы: при M = 1.7 график даёт
θ1 ≈ 40°, текст — 36.4°; при M = 2.5 график даёт θ2 ≈ 20°, откуда G2 = 2.5·sin 20° ≈ 0.86 c1, что невозможно
для квазипоперечной волны (c2 ≈ 0.57 c1). Вероятно, рисунок построен для других параметров или
в других переменных. Решение с двумя ударными волнами у нас существует вплоть до M ≈ 1.01 (материал 1)
и M ≈ 1.005 (материал 2); критерий, по которому автор получил M_min = 1.11, из текста неясен.

**3. Термодинамика.** Автор пишет (стр. 112), что все волны допустимы. По расчёту:
- материал 1, Σ1: D слегка отрицательна (−1.5·10⁻⁴ от масштаба ξ|[W]|), Лакс тоже нарушен
  (1.0091 > G = 1.0080 > 1.0074) — почти вырожденный случай, практически звуковой разрыв;
- материал 2, Σ2: D явно отрицательна (−5 %), Лакс нарушен сильно (0.680 > G = 0.599 > 0.555).
  По правилу самой диссертации (стр. 103) такую волну надо заменить центрированной простой волной.

Интерфейс показывает эти случаи предупреждением и выделяет красным в таблице.

**4. Опечатка в (2.29).** В выражениях для σ21 и σ31 напечатано «(ν + 3β/2)θ», а из потенциала (1.9) —
и из плоской формулы самого автора (1.59) — следует «(ν − 3β/2)θ». Расхождение ~1–2 % в касательных
напряжениях. Похоже, это опечатка набора, а не расчёта: по напечатанной формуле в §2.3 (материал 1)
квазипоперечная волна становится веером с ξ ≈ 0.545 вместо ударной с 0.5671, а в §2.4.1 меняется
порядок волн (Σ1 → Σ3 → веер вместо Σ1 → Σ2 → Σ3); с исправленным знаком всё совпадает с авторскими
результатами. В приложении можно переключить формулу и увидеть это.

**5. §2.4.2: знак β.** Для материала 2 с β = −0.3 (как напечатано на стр. 87) скорость квазипродольной волны
не может быть 1.0424: уже в невозмущённой зоне скорость продольных возмущений равна
√(1 + 2(ν−α−β)/(λ+2μ)) ≈ 1.081. С β = +0.3 решатель даёт Σ1 = 1.0414, Σ3 = 0.6524, веер 0.6518…0.6137 —
совпадение с рис. 18 (1.0424, 0.6532, 0.6526…0.6142) до 0.001. В §2.3 тот же материал считается
с β = −0.3 (ξ1 = 1.08). Вероятно, в расчёте §2.4.2 знак β был другим. Структура волн совпадает при любом знаке.

**6. Рис. 12д, M1(d2) для материала 1.** У автора максимум внутри интервала d2 ∈ [0.001; 0.01]
(значения 1.0066…1.0069), у нас — монотонный выход на насыщение 1.0070…1.0073. Остальные графики
рис. 12/14 совпадают по трендам и диапазонам.

**7. Подписи оси на рис. 13.** На оси p стоят −0.5·10⁻³, −0.6·10⁻³, а в тексте p0 = −0.005. С p0 = −0.0005
получается ξ1 ≈ 1.061 (а не 1.08), с −0.005 — 1.081. Ошибка в подписи рисунка (должно быть 10⁻²).
