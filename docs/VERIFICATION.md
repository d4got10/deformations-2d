# Как проверяется результат

Проверка идёт слоями — от модели материала к сверке с диссертацией. Всё автоматизировано:

```bash
cd app
npm test          # модульные тесты (36 шт.)
npm run report    # таблицы сверки → docs/VERIFICATION_RESULTS.md
npm run build && npm run e2e   # интерфейс в браузере
```

Свежие числа — в [VERIFICATION_RESULTS.md](VERIFICATION_RESULTS.md).

## 1. Модель материала (`tests/material.test.ts`)

- σ = ∂W/∂e: напряжения (1.10) совпадают с численной производной потенциала (1.9) на случайных деформациях.
- Общая формула (1.10) совпадает с явными формулами плоской деформации (1.59) и начальным состоянием (3.2).
- Объективность: поворот тензора деформаций поворачивает тензор напряжений.
- При ν = α = β = 0 — закон Гука; при J2 = 0 напряжения не определены (неаналитичность).

## 2. Предельный переход к линейной упругости

При ν = α = β = 0 решатель обязан дать точное решение: sin θ1 = 1/M, sin θ2 = (c2/c1)/M, скачок градиента
на Σ1 поляризован по нормали (P-волна), на Σ2 — по касательной (S-волна), диссипация равна нулю.
Совпадение — до 9–10 знаков.

## 3. Внутренняя согласованность

- Полная система (3.36) из 10 уравнений (как у автора) выполнена с невязкой < 1e-15, хотя решалась
  сокращённая 6-мерная.
- Граничные условия (3.31), непрерывность перемещений на фронтах, G = M sin θ, θ1 > θ2,
  дополнительное сжатие (3.19).
- Решение не зависит от способа старта; при M ≤ 1 и a0 ≥ 0 задача отвергается.

## 5. Допустимость ударных волн — две независимые проверки

1. **Диссипация** D = [σ_i1 v_i + ξ σ_i2 v_i] + sξ[W + ½ρv²] ≥ 0 — выведена из закона сохранения энергии;
   алгебраически совпадает с (3.30), если в ней брать напряжения перед фронтом.
2. **Условие Лакса**: скорость характеристик того же семейства перед фронтом < G < за фронтом
   (через акустический тензор, независимо от W).

Тест проверяет, что оба критерия всегда дают один и тот же ответ.

## Открытые вопросы к тексту диссертации

**1. θ2 для материала 1.** Расчёт: 19.49°, текст: 19.2° (G2: 0.5672 против 0.5593). Для материала 2 и для θ1
материала 1 всё сходится до 0.05°. Расчётное θ2 почти равно линейному (19.48°): квазипоперечная волна в
материале 1 почти не чувствует разномодульности. Значение автора *ниже* линейного; при той же нелинейности
это соответствует c2/c1 ≈ 0.559 вместо 0.567, т.е. μ ≈ 33.5 вместо 34.8. Возможна опечатка в одном
из модулей материала 1 или иная деталь расчёта у автора.

**2. Рис. 22а и M_min.** Кривые рис. 22а не согласуются с текстом той же страницы: при M = 1.7 график даёт
θ1 ≈ 40°, текст — 36.4°; при M = 2.5 график даёт θ2 ≈ 20°, откуда G2 = 2.5·sin 20° ≈ 0.86 c1, что невозможно
для квазипоперечной волны (c2 ≈ 0.57 c1). Вероятно, рисунок построен для других параметров или
в других переменных. Решение с двумя ударными волнами у нас существует вплоть до M ≈ 1.01 (материал 1)
и M ≈ 1.005 (материал 2); критерий, по которому автор получил M_min = 1.11, из текста неясен.

**3. Термодинамика.** Автор пишет (стр. 112), что все волны допустимы. По расчёту:
- материал 1, Σ1: D слегка отрицательна (−1.5·10⁻⁴ от масштаба ξ|[W]|), Лакс тоже нарушен
  (1.0091 > G = 1.0080 > 1.0074) — почти вырожденный случай, практически звуковой разрыв;
- материал 2, Σ2: D явно отрицательна (−5 %), Лакс нарушен сильно (0.680 > G = 0.599 > 0.555).
  По правилу самой диссертации (стр. 103) такую волну надо заменить центрированной простой волной.

Интерфейс показывает эти случаи предупреждением и выделяет красным в таблице.
