# План проекта

Веб-приложение для визуализации плоских деформаций разномодульной упругой среды по мотивам
диссертации О.В. Дудко «Динамика разномодульной изотропной упругой среды при ударных воздействиях»
(ИАПУ ДВО РАН, 1998), файл [`sources/disser.pdf`](../sources/disser.pdf).

## Этап 1 (сделан) — подвижная нагрузка, §3.2

Нагрузка σ11*, σ21* движется по границе предварительно сжатого полупространства со сверхсейсмической
скоростью s = M·c1. Возникают квазипродольная Σ1 и квазипоперечная Σ2 ударные волны; в трёх зонах
(0, I, II) деформации однородны.

**Модель** — потенциал Мясникова–Олейникова (1.9), напряжения (1.10)/(1.59), малые деформации.

**Решение.** Система (3.36): 10 нелинейных уравнений. Непрерывность перемещений (3.28) линейна по b, n,
поэтому они исключены; Ньютону остаётся 6 неизвестных (a1, k1, a2, k2, ξ1, ξ2). Начальное приближение —
решение линейной теории (конусы Маха + поляризация P/S-волн), затем продолжение по параметру ε,
масштабирующему ν, α, β от 0 до 1. Кривые θ(M), θ(σ*) — продолжением от соседней точки.

**Структура кода** (`app/`):

| Файл | Назначение |
|---|---|
| `src/core/material.ts` | инварианты (1.60), напряжения (1.10), потенциал (1.9) |
| `src/core/newton.ts` | Гаусс, демпфированный Ньютон |
| `src/core/movingLoad.ts` | постановка §3.2, невязки (3.36), решатель, диссипация (3.30), продолжение |
| `src/core/acoustic.ts` | акустический тензор, условие Лакса — независимая проверка допустимости фронтов |
| `src/core/presets.ts` | материалы и случаи из диссертации, эталонные числа |
| `src/ui/*` | интерфейс: сцена (Canvas2D), SVG-графики, панель параметров |
| `tests/*` | модульные тесты (Vitest) |
| `scripts/report.ts` | генерирует `docs/VERIFICATION_RESULTS.md` |
| `scripts/e2e.mjs` | проверка интерфейса в Chromium (Playwright) |

**Визуализация.** Подвижная система координат, связанная с L0: картина стационарна, материальная сетка
протекает через фронты. Поле перемещений кусочно-линейно, поэтому зоны и сетка рисуются точно
(аффинный образ каждой зоны, изломы ровно на фронтах). Регулируемое увеличение перемещений, раскраска
по σ11, σ12, σ22, σ33, объёмной деформации, скорости; ступенчатые диаграммы как на рис. 21; кривые θ как на
рис. 22/24 с линейной теорией и точками из диссертации.
