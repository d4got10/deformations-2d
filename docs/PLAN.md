# План проекта

Веб-приложение для визуализации плоских деформаций разномодульной упругой среды по мотивам
диссертации О.В. Дудко «Динамика разномодульной изотропной упругой среды при ударных воздействиях»
(ИАПУ ДВО РАН, 1998), файл [`sources/disser.pdf`](../sources/disser.pdf).

## Этап 1 (сделан) — подвижная нагрузка, §3.2

Нагрузка σ11*, σ21* движется по границе предварительно сжатого полупространства со сверхсейсмической
скоростью s = M·c1. Возникают квазипродольная Σ1 и квазипоперечная Σ2 ударные волны; в трёх зонах
(0, I, II) деформации однородны.

**Модель** — потенциал Мясникова–Олейникова (1.9), напряжения (1.10)/(1.59), малые деформации.

**Решение.** Система (3.36): 10 нелинейных уравнений. Непрерывность перемещений (3.28) линейна по b, n,
поэтому они исключены; Ньютону остаётся 6 неизвестных (a1, k1, a2, k2, ξ1, ξ2). Начальное приближение —
решение линейной теории (конусы Маха + поляризация P/S-волн), затем продолжение по параметру ε,
масштабирующему ν, α, β от 0 до 1. Кривые θ(M), θ(σ*) — продолжением от соседней точки.

**Структура кода** (`app/`):

| Файл | Назначение |
|---|---|
| `src/core/material.ts` | инварианты (1.60), напряжения (1.10), потенциал (1.9) |
| `src/core/newton.ts` | Гаусс, демпфированный Ньютон |
| `src/core/movingLoad.ts` | постановка §3.2, невязки (3.36), решатель, диссипация (3.30), продолжение |
| `src/core/acoustic.ts` | акустический тензор, условие Лакса — независимая проверка допустимости фронтов |
| `src/core/presets.ts` | материалы и случаи из диссертации, эталонные числа |
| `src/core/material1d.ts` | напряжения и потенциал при одномерной деформации (p, g, s), формула (2.29) |
| `src/core/impact.ts` | глава 2: ударные волны, вееры, нейтральная волна, законы сохранения |
| `src/ui/*` | интерфейс: сцена (Canvas2D), SVG-графики, панель параметров |
| `tests/*` | модульные тесты (Vitest) |
| `scripts/report.ts` | генерирует `docs/VERIFICATION_RESULTS.md` |
| `scripts/e2e.mjs` | проверка интерфейса в Chromium (Playwright) |

**Визуализация.** Подвижная система координат, связанная с L0: картина стационарна, материальная сетка
протекает через фронты. Поле перемещений кусочно-линейно, поэтому зоны и сетка рисуются точно
(аффинный образ каждой зоны, изломы ровно на фронтах). Регулируемое увеличение перемещений, раскраска
по σ11, σ12, σ22, σ33, объёмной деформации, скорости; ступенчатые диаграммы как на рис. 21; кривые θ как на
рис. 22/24 с линейной теорией и точками из диссертации.

## Этап 2 (сделан) — удар по границе, глава 2

Нормальный (§2.3) и косой (§2.4) удар по предварительно деформированному полупространству.
Состояние — (p, g, s) = (u1,1, u2,1, u3,1), автомодельная переменная ξ = x1/(c1 t).

**Решатель** (`src/core/impact.ts`): общая задача о распаде разрыва. В плоскости поляризации (p, |τ|)
ищутся две волны — квазипродольная и квазипоперечная, каждая ударная (Ньютон по условиям (2.40)–(2.42))
или веер (интегрирование RK4 вдоль собственного вектора акустического тензора). Перебираются все четыре
комбинации, выбирается допустимая по Лаксу. Нейтральная волна (поворот сдвига, ξ² = Φ) ставится туда,
где её скорость укладывается между соседними волнами — так автоматически получаются обе постановки §2.4.
Граничные условия: скорость границы (§2.3) или деформации/напряжения на границе (§2.4).

**Визуализация** (`src/ui/impactPage.ts`): два сечения материала — (x1, x2) с u1, u2 и (x1, x3) с u1, u3,
анимация по времени, автоматическое увеличение перемещений; диаграмма x–t; профили по ξ как на
рис. 11, 13, 16, 18; скорости волн от интенсивности удара как на рис. 12, 14; переключатель формулы
напряжений (1.9) / напечатанная (2.29).

## Этап 3 (сделан) — 3D-вид для главы 2

Переключатель «2D сечения / 3D» над сценой. Брусок материала x1 ∈ [0, Xmax], |x2|, |x3| ≤ h:
сечения x1 = const сдвигаются как целое на (u1, u2, u3), продольные материальные линии изгибаются в
пространстве. Фронты волн — полупрозрачные плоскости, ось бруска выделена (её излом показывает
поляризацию сдвига, поворот на нейтральной волне), стрелки — нагрузка на границе. three.js загружается
лениво только при включении 3D (`src/ui/impact3d.ts`), камера вращается мышью.

## Этап 4 (сделан) — серия нормальных ударов

Несколько импульсов скорости границы (начало, длительность, скорость d). Волны разных ударов
встречаются, решение перестаёт быть автомодельным, поэтому считается численно:
`src/core/fv1d.ts` — конечные объёмы, MUSCL (minmod) + поток Русанова, SSP-RK2, зеркальные фиктивные
ячейки для заданной скорости границы. Расчёт идёт в Web Worker (`src/ui/seriesWorker.ts`).
Страница `src/ui/seriesPage.ts`: сечение материала в выбранный момент, цветная диаграмма x–t
(p, s, v1, σ11), профили по x с наложением точного решения §2.3 до первого изменения скорости границы,
график скорости и перемещения границы, баланс кинематики и энергии; 3D-вид бруска (тот же модуль
`impact3d.ts`, теперь по экземпляру на вкладку) с отдельным увеличением сдвиговых перемещений —
при нормальном ударе они в сотни раз меньше продольных.

Проверка численного решателя по точному (`tests/fv1d.test.ts`): сходимость к автомодельному решению
при измельчении сетки; второй удар по уже движущейся сжатой среде и остановка границы (разгрузка)
сверяются с точным решением с ненулевой скоростью среды впереди (`ImpactProblem.v0`);
кинематический баланс выполняется до 1e-15; работа границы = прирост энергии + рассеяние, рассеяние
убывает с сеткой.

## Возможные следующие этапы

- §2.1 — отражение продольной волны от свободной поверхности (не автомодельная задача, решение Даламбера).
- Нормальный удар с касательной скоростью границы (сейчас v* = (d*, 0, 0)).

- §3.2: замена недопустимой ударной волны на простую (механизм вееров уже есть в решателе главы 2).
- §3.3 — соударение двух разномодульных тел (система (3.58), сцепление/скольжение).
- Одномерные задачи главы 2.
- Независимый нестационарный решатель (отложен по решению заказчика).
- Публикация на GitHub Pages.
