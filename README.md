# deformations-2d

Визуализация плоских деформаций разномодульной упругой среды по мотивам диссертации
О.В. Дудко «Динамика разномодульной изотропной упругой среды при ударных воздействиях» (1998).

Реализовано (модель Мясникова–Олейникова):

- **глава 2** — удар по всей границе предварительно деформированного полупространства: нормальный (§2.3)
  и косой (§2.4); ударные, простые (вееры) и нейтральные волны, тип волн выбирается автоматически; есть 3D-вид бруска материала;
- **серия ударов** — несколько нормальных ударов с интервалами; нестационарный численный решатель,
  сверенный с точным решением главы 2;
- **§3.2** — постоянная нагрузка движется со сверхсейсмической скоростью по границе (две ударные волны).

## Запуск

```bash
cd app
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://localhost:5173).

## Публикация

Сайт: https://d4got10.github.io/deformations-2d/ (ветка `gh-pages`).
Обновить после изменений:

```bash
bash app/scripts/deploy.sh
```
